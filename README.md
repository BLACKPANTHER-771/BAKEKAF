# Maison Crème — Luxury Artisan Bakery & Café Website

> **Baked slowly. Loved deeply.**

A premium, production-ready frontend website demo built for artisanal bakeries, boutique pâtisseries, and specialty cafés. Designed to serve as a high-converting client showcase for freelancing sales.

---

## ✨ Features & Architecture

- **Centralized Business Configuration (`src/data/bakeryData.js`)**: All business details (brand name, address, opening hours, WhatsApp number, phone, menu items, prices, reviews, offers, gallery, Razorpay payment link) are stored in one file. Effortlessly rebrand this project for new clients in under 5 minutes.
- **Direct WhatsApp Ordering**: One-click WhatsApp link generation with customized order details, pre-filled prices, quantities, and special notes.
- **Interactive Custom WhatsApp Order Drawer**: Allows patrons to build a custom box with multiple items and quantities and send the itemized summary directly to WhatsApp.
- **Categorized Artisanal Menu**: Tabbed navigation across Cakes, Pastries, Specialty Coffee, Desserts, Sourdough Breads, and Beverages, complete with real-time dietary filters (Eggless/Veg toggle) and live search.
- **Product Quick View Modal**: Flavor notes, ingredients, dietary indicators, quantity selectors, and direct WhatsApp order actions.
- **Editorial Story & Philosophy Section**: Includes stat counters, chef ethos, and an interactive chronicle modal.
- **Masonry Visual Photo Journal**: Responsive gallery grid with category filters and image lightbox modal.
- **Customer Love & Reviews**: 4.9★ rating summary, verified review cards, and direct Google Review link.
- **Location & Interactive Google Maps**: Live operating hours badge, formatted address with one-click copy, direct call, and Google Maps embed with driving directions.
- **Payment-Ready Architecture**: Built-in Razorpay / UPI link configuration modal ready for client payment gateway integration.
- **Mobile-First Sticky Bottom Action Bar**: Fast access to WhatsApp ordering, direct phone calling, and menu navigation.
- **SEO & Accessibility**: Complete Open Graph metadata, semantic HTML5 hierarchy, and Schema.org `LocalBusiness` / `Bakery` structured data.
